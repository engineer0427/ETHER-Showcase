# ETHER — IESA (Information-Entanglement Stabilization Algorithm)

**이징형 국소 탐색에 전역 다수결 갱신을 더하는 최적화 알고리즘과 그 구현에 관한 개인 연구 프로젝트**

> 이 문서는 특허 정규출원 전까지 쓰는 임시 안내문이다. 정규출원 후 새 버전 논문 공개와 함께 갱신할 예정이다.
> 소스코드는 비공개 저장소에서 관리한다.

- 특허: 출원 진행 중 (제 10-2026-0127949 호)
- 논문: Zenodo, 모든 버전을 묶는 대표 DOI [10.5281/zenodo.21311203](https://doi.org/10.5281/zenodo.21311203) (항상 최신 버전으로 연결)
- 개발: 한정우 (개인 브랜드 란더, Landauer)

## 핵심 아이디어

스핀 N 개로 이루어진 이징형 문제에서, 국소 갱신(무작위 노드 하나를 에너지 변화에 따라 뒤집기)에 다음을 더한다.

- **전역 합의 상수 시간 추적**: 전체 스핀 합 S 를 매번 다시 세지 않고, 스핀이 바뀔 때마다 ±2 만 더해 O(1) 로 갱신한다.
  (이런 증분 추적 자체는 몬테카를로 시뮬레이션에서 표준적인 방법이다.)
- **전역 다수결 갱신**: 확률 κ 로 무작위 노드 하나를 S 의 부호(전체 다수 방향)로 맞춘다.

1차원 강자성 사슬처럼 국소 갱신만으로는 정렬이 느린 문제에서 수렴을 크게 앞당기는 것을 측정으로 확인했고,
일반적인 결합 구조로 확장하는 연구를 진행했다. 자세한 결과는 정규출원 후 공개할 새 버전 논문에 정리한다.

## 수정 이력

- 2026-10: 이전 버전의 안내문과 논문(버전 2)에 있던 일부 주장은 이후 사전에 정한 기준으로 시험한 결과 지지되지 않아 철회했다.
  상태 전이가 서브 리니어로 증가한다는 주장, κ 가 0.5 이하여야 한다는 주장, 란다우어 한계 근처에서 동작한다는 주장,
  산업 분야별 적용 효과에 관한 서술이 여기에 해당한다. 아직 진행되지 않은 제도 활용·파트너십 관련 서술도 삭제했다.
