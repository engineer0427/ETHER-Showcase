# ETHER — IESA

**전역 상태 합의 상수 시간 추적과 확률적 전역 다수결 갱신을 이용한 조합 최적화 알고리즘과 그 하드웨어 구현에 관한 개인 연구 프로젝트**

- 특허: 출원 제 10-2026-0225723 호 (출원일 2026-11-12, 우선일 2026-07-13)
  발명의 명칭: 전역 상태 합의 상수 시간 추적과 확률적 정보 얽힘 갱신을 이용한 조합 최적화 연산 장치 및 방법
- 논문: Zenodo, 모든 버전을 묶는 대표 DOI [10.5281/zenodo.21311203](https://doi.org/10.5281/zenodo.21311203) (항상 최신 버전으로 연결)
- 소스코드: 비공개 저장소에서 관리
- 개발: 한정우 (개인 브랜드 란더, Landauer)

## 풀려는 문제

노드 N 개, 각 노드의 상태 s_i ∈ {-1, +1}, 노드 쌍의 결합값 J_ij 로 표현되는 문제에서
에너지 E = -Σ J_ij s_i s_j 가 낮은 상태를 찾는다. Max-Cut 같은 조합 최적화 문제가 이 형태로 바뀐다.

노드 하나씩 뒤집어 보는 국소 갱신은 단순하지만, 결합 대부분이 같은 부호인 문제에서는
서로 다른 상태의 영역이 맞닿은 경계가 잘 사라지지 않아 정렬이 느려진다.
전체 상태를 보면 이 경계를 풀 수 있지만, 매번 전체를 다시 세면 노드 수에 비례하는 비용이 든다.

## 방법

국소 갱신 위에 다음 네 가지를 더한다.

1. **전역 상태 합의 상수 시간 추적**
   전체 상태 합 S 를 매번 다시 세지 않고, 노드가 바뀔 때마다 변화분(±2)만 더한다.
   이런 증분 추적 자체는 몬테카를로 시뮬레이션에서 표준적인 방법이며, IESA 는 이것을 아래 갱신의 판단 근거로 쓴다.
2. **전역 다수결 갱신**
   확률 κ 로 무작위 노드 하나를 골라, S 의 부호(전체의 다수 방향)와 다르면 그 방향으로 바꾼다.
3. **시작 판정**
   연산 전에 결합 부호 비율 ρ = ΣJ / Σ|J| 를 한 번 계산해, 기준값 이상일 때만 전역 다수결 갱신을 쓴다.
   결합의 상당 부분이 반대 부호인 문제(스핀글라스, Max-Cut 등)에서는 처음부터 쓰지 않는다.
4. **에너지 장부 감시**
   전역 다수결 갱신이 일으킨 에너지 변화를 판단 주기마다 누적하고,
   기준을 두 주기 연속으로 넘으면 전역 다수결 갱신을 끈다. 끈 뒤에는 다시 켜지 않는다.

국소 갱신의 수용 규칙으로는 탐욕적 판정, 메트로폴리스 판정, 로지스틱 판정을 시험했다.

## 하드웨어 구현

정수 연산 디지털 회로(FPGA 또는 ASIC)로 구현하는 구조를 설계했다.
차분 연산기, 전역 레지스터, 난수 생성기, 노드 선택기, 국소장 메모리, 수용 판정기,
장부 누산기 및 비교기, 2비트 연속 카운터로 이루어지며, 결합값은 8비트 정수로 양자화한다.

정수 연산 구현은 9개 문제 모두에서 사전에 정한 기준(최저 에너지, 강자성 문제의 노드당 상태 반전, 비활성화 동작) 안에서
실수 연산 구현과 통계적으로 같았다(시드 40개).

## 한계

- 이점은 결합 대부분이 같은 부호인 문제에서 나온다. 좌절이 큰 문제에서는 전역 다수결 갱신을 끄므로 국소 갱신과 같다.
- 정확한 최적해와 비교한 것은 N = 20 뿐이고, 그보다 큰 문제는 국소 갱신 대비로 평가했다. 검증한 크기는 N = 20 ~ 1,024 (1차원 사슬은 100,000 까지).
- 에너지 장부 감시가 실제로 해로운 상황을 잡아낸 사례는 아직 없다. 지금까지는 잘못 끄지 않는다는 것만 확인했다.
- 결합 부호 비율이 높아도 영역이 갈린 일부 문제에서는 메트로폴리스 판정과 함께 쓸 때 국소 갱신보다 약간 나빴다.
- 상태 반전이 줄어드는 것은 디지털 회로의 스위칭 활동을 줄이는 방향이지만, 실제 전력 절감은 측정하지 않았다.
